# Graded evidence checklist

Capture evidence from your own environment; do not create screenshots or terminal logs that claim actions succeeded when they have not.

Suggested output files requested by the assignment:
- `rest-create-done`
- `rest-list-done`
- `rest-read-done`
- `rest-update-done`
- `rest-delete-done`
- `ci-workflow-done`
- `security-headers-done`
- `kube-app-output`
- `kube-images`
- `kube-deploy-accounts`
- `pipelinerun.txt`

Kanban screenshots must show the actual course board with the specified story in the required column. A GitHub code upload alone does not create those board states or prove a pipeline ran.
